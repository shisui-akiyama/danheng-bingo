# 丹恒ビンゴ

『崩壊：スターレイル』の丹恒、丹恒・飲月、丹恒・騰荒を題材にした、非公式ファンメイドのビンゴゲームです。

## 遊び方

1. 「次のコール」を押して、コールされる項目を確認します。
2. ビンゴカードに同じ項目があれば、そのマスをタップします。
3. 縦・横・斜めのいずれか1列、5マスがそろうとビンゴです。
4. カードにない項目は「カードになし（通過）」でスキップできます。
5. ヒントを使うとミスカウントが増えます。誤タップにも注意してください。

## 起動方法

ビルドや外部ライブラリは不要です。

- `index.html` をダウンロードして、ブラウザで開くと遊べます。
- GitHub Pagesを使う場合は、このリポジトリをGitHubに作成して `index.html` をルートに置き、リポジトリの **Settings → Pages** から公開設定を行ってください。

## 技術メモ

- HTML / CSS / JavaScriptで構成したシングルページゲームです。
- 画像はHTML内にデータとして埋め込んでいるため、画像ファイルの別アップロードは不要です。
- ベストスコアの保存にブラウザの `localStorage` を使用します。保存内容は利用中のブラウザ内に保持されます。
